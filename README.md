# FastBox Courier

Proyecto web desarrollado para gestionar y consultar información relacionada con envíos mediante el sistema FastBox Courier.

El proyecto está dividido en una parte principal del sistema y una página destinada al consumidor, donde se puede consultar la información proporcionada por la API.

### FastBox Courier

Sistema principal del proyecto:

**[Abrir FastBox Courier](https://sebaesco.alwaysdata.net/)**

Esta página corresponde al sistema principal publicado en AlwaysData.

### FastBox Consumer

Página desarrollada para consumir y mostrar la información proporcionada por la API:

**[Abrir FastBox Consumer](https://fastboxconsumer.42web.io/)**

Esta versión se encuentra publicada en InfinityFree.

## Código del proyecto

En este repositorio se encuentran los archivos utilizados para desarrollar las páginas, junto con la documentación correspondiente.

La carpeta `sistema` contiene los archivos relacionados con FastBox Courier y la carpeta `consumer` contiene los archivos utilizados para la página consumidora.

## Objetivo

El objetivo del proyecto es desarrollar una solución web relacionada con el manejo de envíos, conectando una aplicación con una API para consultar y mostrar la información de los servicios disponibles.
